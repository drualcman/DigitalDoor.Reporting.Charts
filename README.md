# DotNetBasics.Charts
Simple charts (Bars, Columns, Pie, Lines, Ring percentage) generated as SVG from .NET code.
It works in any .NET application: ASP.NET Core, Blazor Server, Blazor WebAssembly, MVC and console apps.

The result is an SVG `string`, so it can be written to a file, returned from an API, shown in a web page or used as an image in a PDF or HTML report.
